# Python Profile Generator

A small command-line Python program that collects a few details about a person and prints them as a formatted profile card.

## Why use it?

- Turns a name, age, city, and occupation into a readable profile.
- Demonstrates basic Python input, strings, formatting, and output.
- Runs with Python alone; there are no third-party dependencies.

## Get started

You need Python 3.6 or newer. Clone or download this repository, then run the script from its directory:

```bash
python "Profile Generator.py"
```

Enter your first name, last name, age (as a whole number), city, and occupation when prompted. For example:

```text
Enter your first name: Grace
Enter your last name: Hopper
Enter your age: 36
Enter your city: London
Enter your occupation: Teacher
```

The program prints a profile card with those details and a short first-person description. The city and occupation are displayed in title case.
